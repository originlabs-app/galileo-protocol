L2051@P41: 9.3.10 SDM Session Key Generation
L2052@P41: For Secure Dynamic Messaging for reading, the following session keys are calculated:
L2053@P41: • SesSDMFileReadMACKey for MACing of file data.
L2054@P41: • SesSDMFileReadENCKey for encryption of file data
L2055@P41: The session key generation is according to NIST SP 800-108 [8] in counter mode.
L2056@P41: The pseudo random function applied during the key generation is the CMAC algorithm
L2057@P41: described in NIST Special Publication 800-38B [6]. The key derivation key is the
L2058@P41: SDMFileReadKey as configured with the SDMFileRead access right.

L2249@P43: 10 Tag Tamper Protection
L2250@P43: NT4H2421Tx offers an NFC Forum-compliant solution to reflect e.g. if the sealing of
L2251@P43: a product is opened. This solution works without a dedicated application on a mobile
L2252@P43: phone. It only requires the capability of reading out NFC Forum Type 4 Tag [14].
L2253@P43: NT4H2421Tx contains four pads, where two are used for antenna connection and the
L2254@P43: other two will connect a detection wire as illustrated in Figure 13. During the execution
L2255@P43: of the first command that is sent after ISO/IEC 14443-4 activation, the IC checks the tag
L2256@P43: tamper wire. If opened, this status will be recorded as permanent status in NVM. The
L2257@P43: result can be reflected in the NDEF message. Next to this, NT4H2421Tx also supports
L2258@P43: a specific command that triggers a measurement and returns both the permanent and
L2259@P43: current status. This chapter describes how the feature is enabled, when the check is
L2260@P43-44: executed and how the status can be retrieved.NXP Semiconductors NT4H2421Tx

L2267@P44: 10.1 Enabling the Tag Tamper feature
L2268@P44: At delivery, NT4H2421Tx has the tag tamper feature disabled. The feature can be
L2269@P44: enabled by SetConfiguration with Option 07h, see Section 11.5.1. Once enabled,
L2270@P44: the NT4H2421Tx starts Tag Tamper measurements, see Section 10.2 from the next
L2271@P44: activation onwards. A measurement can always be triggered by issuing a GetTTStatus
L2272@P44: command.
L2273@P44: When enabling the Tag Tamper feature using SetConfiguration, the access right related
L2274@P44: with TTStatusKey for GetTTStatus for Tag Tamper Status retrieval can be set, see
L2275@P44: Section 10.3.2. Enabling the Tag Tamper feature is permanent, it cannot be disabled
L2276@P44: once enabled.
L2277@P44: 10.2 Tag Tamper measurements
L2278@P44: NT4H2421Tx maintains a permanent Tag Tamper status TTPermStatus. The
L2279@P44: TTPermStatus and the current status TTCurrStatus can be mirrored together in the
L2280@P44: NDEF file, and included in the Secure Dynamic Messaging, see Section 9.3. Both
L2281@P44: statuses can also be retrieved with GetTTStatus. The following values are supported:
L2282@P44: • Close: 43h, i.e. ASCII encoding of ‘C’. This is the initial value when the seal is still
L2283@P44: closed.
L2284@P44: • Open: 4Fh, i.e. ASCII encoding of ‘O’. This is the value when the seal was opened.
L2285@P44: • Invalid: 49h, i.e. ASCII encoding of ‘I’. This is the value when the feature has not been
L2286@P44: enabled yet and no measurements are executed.
L2287@P44: Once the feature has been enabled, NT4H2421Tx measures whether the seal is opened
L2288@P44: by applying a measurement on the detection wire. As the NTAG 424 DNA TT is a
L2289@P44: passive tag, it cannot trigger measurements itself. The measurement will be done, each
L2290@P44: time the tag is powered and booted. If the current TTPermStatus is still set to Close, the
L2291@P44: measurement will only be done after complete ISO/IEC 14443-4 activation and during
L2292@P44: processing of the first command.
L2293@P44: If a measurement detects the seal to be opened, the TTPermStatus is updated to
L2294@P44: Open. Once set to Open, the measurement on boot will not be triggered anymore. The
L2295@P44: TTPermStatus cannot be reset to Close anymore.
L2296@P44: The following commands also trigger a measurement once the feature is enabled:
L2297@P44-45: • GetTTStatus, see Section 10.3.2.NXP Semiconductors NT4H2421Tx
