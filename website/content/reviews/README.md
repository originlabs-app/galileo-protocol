# Article review dossiers

One folder per published article slug:
`website/content/reviews/<slug>/`.

When an article quotes a named person, a social post, or the press, add
`citations.md` in that folder. Each entry lists:

- exact verbatim
- author
- original date
- live URL
- capture date and time
- PNG screenshot or text export readable without an origin-platform account

If the article has no attributed quotation, skip the file. The rule is
not applicable and does not block review.
